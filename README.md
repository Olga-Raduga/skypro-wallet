# 💳 SkyproWallet

Веб-приложение для удобного учёта, контроля и анализа личных расходов. 

## 🛠️ Стек технологий
- **Фреймворк:** Vue 3 (Composition API)
- **Сборщик проекта:** Vite
- **Маршрутизация:** Vue Router
- **Работа с API и стили:** Fetch API, CSS
- **Качество кода:** ESLint / Prettier

## 📂 Структура и маршруты
В приложении настроена маршрутизация и реализованы следующие страницы:
- `/login` — Экран входа в систему
- `/register` — Экран регистрации нового пользователя
- `/expenses` — Главная страница расходов (таблица фильтр и форма добавления)
- `/analysis` — Страница анализа расходов, календарь периода и диаграмма

## ✨ Ключевые функции

- **Авторизация / регистрация** — валидация форм со звёздочками, вывод серверных ошибок, сохранение токена
- **Защита роутов** — приватные страницы доступны только только авторизованным пользователям
- **Управление расходами** — загрузка списка транзакций с сервера, добавление новых записей и удаление выбранных строк
- **Фильтр по периоду** — выбор диапазона дат
- **Диаграмма по категориям** — перестроение при смене периода
- **Календарь периода** — выбор периода в календаре (включая прошлые месяцы)
- **Адаптивная вёрстка** — корректное отображение на разрешениях от 320px до 1440px

## 🚀 Запуск и разработка

> Перед запуском убедитесь, что у вас установлена актуальная версия Node.js.

1. **Установка зависимостей проекта:**
   ```bash
   npm install
   ```

2. **Запуск приложения в режиме разработки (локальный сервер):**
   ```bash
   npm run dev
   ```

3. **Проверка и автоматическое форматирование кода линтером:**
   ```bash
   npm run lint
   ```

4. **Сборка проекта для production:**
   ```bash
   npm run build
   ```
5. **Клонирование репозитория:**
   ```bash
   git clone https://github.com
   ```   

## 🟢 Реализовано
Проект реализован полностью — **весь запланированный функционал работает**:
- Вёрстка всех страниц по макету (включая мобильную)
