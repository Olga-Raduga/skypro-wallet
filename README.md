# 💳 SkyproWallet

Веб-приложение для удобного учёта, контроля и анализа личных расходов. 

## 🛠️ Стек технологий
- **Фреймворк:** Vue 3 (Composition API)
- **Сборщик проекта:** Vite
- **Маршрутизация:** Vue Router
- **Качество кода:** ESLint / Prettier

## 📂 Текущая структура и маршруты
На данном этапе инициализирована основа проекта, настроена базовая архитектура папок и подготовлены маршруты для следующих страниц-заглушек:
- `/login` — Экран входа в систему
- `/register` — Экран регистрации нового пользователя
- `/expenses` — Главная страница расходов (таблица и навигация)
- `/analysis` — Страница анализа расходов и календарь

## 🚀 Запуск и разработка

> Перед запуском убедитесь, что у вас установлена актуальная версия Node.js.

1. **Установка зависимостей проекта:**
   ```bash
   npm install
   ```

2. **Запуск приложения в режиме разработки (локальный сервер):**
   ```bash
   npm run dev
   ```

3. **Проверка и автоматическое форматирование кода линтером:**
   ```bash
   npm run lint
   ```

4. **Сборка проекта для production:**
   ```bash
   npm run build
   ```
